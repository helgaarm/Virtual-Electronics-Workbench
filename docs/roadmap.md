# Roadmap

- **Phase A — complete in this milestone:** realistic 3D breadboard, camera inspection, real scale, snapping, selection, rotation, physical component rendering.
- **Phase B — complete in this milestone:** electrical extraction, DC source/resistor/switch/LED models, power control, live voltage/current feedback, SQLite project persistence.
- **Phase C — complete in this milestone:** deeper Test & Analysis workspace, persistent multimeter readings, and attachable probe workflow.
- **Phase D:** capacitor and transient engine with verified RC response.
- **Phase E:** oscilloscope and signal generator driven only by simulated samples.
- **Later:** expanded analogue/digital parts, ICs, firmware, experiments, faults and hardware-in-the-loop.
